# Розробка

Статична гра на Canvas та JavaScript modules, без зовнішніх залежностей. Усі шляхи відносні, тому проєкт працює під шляхом репозиторію на GitHub Pages.

## Файли

- `engine.mjs`: фізика, стани, таймери, пози падіння.
- `game.mjs`: керування, камера, малювання, розміщення хмаринок.
- `phone-rig.mjs`: єдина рухома частина руки; смартфон і тулуб зафіксовані.
- `controls.mjs`: незалежні дотики двох рук.
- `dialogue-data.mjs`: усі тексти, характери, ніки, стартова сцена Полтави.
- `dialogue.mjs`: черга реплік, паузи, час читання, реакції та обмеження частоти.
- `assets/`: 20 локальних зображень.
- `tests/`: фізика, падіння, дотики, телефон і діалоги.

## Контракти анімацій

У ходьбі та спокої кадр 384×512, сітка 4×2, атлас 1536×1024. Верх силуету 44, підошви 480. Початкова восьмикадрова ходьба збережена. Масштаби: Славік 1, Даша 0.91, Катя 0.82.

Падіння використовує окремі вихідні зображення й зареєстровані частини кадру. Голова вирівняна за відповідною ігровою моделлю, підлога лишається 480. У фіналі береться точний спрайт спокою. Не визначати підлогу за цілим прямокутником комірки: сусідній кадр може перетинати межу. Виправлена посадка Каті виключає таку домішку.

При свайпі повне передпліччя обертається навколо ліктя. Для Даші ширина руки, кисті та стику збільшена поперек осі без зміни довжини. Не повертати прямокутні рухомі латки на тулуб.

## Діалоги

ID реплік унікальні. `speaker` посилається на профіль; `text` — чистий текст без розмітки. `trigger` задає ситуацію. `pauseBeforeMs` задає паузу, а не порожню промовлену репліку. `scene.startingPositions` містить позиції й напрямки на початку.

Репліки показуються послідовно; для довших фраз дається більше часу. Якщо герой поза кадром або падає, його хмаринка не показується. Перед майбутньою озвучкою зістав аудіофайли з ID та додай синхронізацію тривалості; текст і мовці вже відокремлені. Поточна версія не використовує синтез мовлення.

## Збірки

`npm test` перевіряє поведінку гри та ресурси. `npm run build` збирає `_site/`. `npm run offline` вбудовує код, стилі та всі зображення в один HTML. Нові модулі додавати до списку `modules` у `scripts/lib.mjs`, а зображення — до `assetFiles` у `game.mjs`.

`docs/` — документація й знімок текстів/метаданих. Основне джерело реплік — `dialogue-data.mjs`.
