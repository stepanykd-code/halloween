# Графіка й тексти

У `assets/` — фінальні локальні зображення трьох персонажів, їхніх анімацій, двох здібностей кожного, чотирьох босів, рук-привидів, скрімера, шарів Полтави та обох місяців. Малюнки створені для цього проєкту за погодженими референсами.

`docs/release.json` перелічує контрольні суми ресурсів поточної версії. Розміри й прозорість перевіряє `scripts/validate-assets.mjs`. Кадри зберігають погоджені пропорції та опорні точки.

`character-dialogue-uk.md` і JSON — поточні репліки та діалоги. Тексти написані для дітей 12–14 років та вигаданої хелоуїнської пригоди в Полтаві. `preview.png` показує сцену гри.
