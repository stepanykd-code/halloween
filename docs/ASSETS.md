# Графіка й тексти

Персонажі та хелоуїнський фон створені для цього проєкту вбудованим image_gen за референсами. У `assets/` — фінальні локальні зображення ходьби, спокою, присідання, смартфона, шарів руки та падіння.

`animation-metadata.json` описує смартфони; `fall-metadata.json` — реєстрацію падіння, голови та рівня землі. Нові промпти падіння збережено в `fall-prompts.txt`.

`character-dialogue-uk.md` та JSON — знімок реплік і профілів. Тексти написані для дітей 12–14 років і вигаданої хелоуїнської пригоди в Полтаві. `preview.png` показує актуальну сцену з хмаринкою.
